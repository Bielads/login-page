# 🔐 Login Page

Projeto de uma página de login desenvolvido para praticar os fundamentos do desenvolvimento web.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎯 Objetivo

Praticar a criação de interfaces web, organização de elementos HTML e estilização com CSS.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo HTML principal no navegador.

## 📚 Aprendizados

- Estrutura básica de uma página HTML.
- Estilização com CSS.
- Organização de arquivos de um projeto web.
